Detailed Description

Class that implements an action executor using Behavior Trees.

This class provides a framework for executing PDDL actions using Behavior Trees. It loads and executes a BT from an XML file and handles the lifecycle operations.

BTAction ( const std::string & action,
BT::Blackboard::Ptr parent )

Constructor for a BTAction that shares a blackboard with others (#315).

The blackboard of its tree is a child of parent: as in BehaviorTree.CPP, keys starting with '@' (e.g. "@battery") are those of parent, so they are shared by all the BTActions created with it in the same process.
