Detailed Description

ROS2 Lifecycle node that manages plan execution.

This node receives plans to execute, transforms them into behavior trees, and monitors their execution. It also provides services to retrieve information about the current execution state and supports replanning when necessary.

◆ skip_finished_actions()

std::vector< std::pair< std::string, ActionExecutionInfo > > skip_finished_actions ( PlanRuntineInfo & runtime_info,
const std::map< std::string, ActionExecutionInfo > & previous_action_map )
protected

Take out of a new plan the actions the previous one just finished.

A plan computed while an action ran can reach the executor after it ended: it starts with that action, whose requirements hold no more. The first time each such action appears is taken out; a later one is the plan doing it again.

Parameters
[in,out]runtime_infoRuntime information with the new plan.
[in]previous_action_mapThe actions of the previous plan.
Returns
The actions taken out, with their new ids and the information of when they ran.
