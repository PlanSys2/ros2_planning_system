Detailed Description

The node a PlanSys2 client works on, which it does not own: one of a component or of an application.

The clients and subscriptions of the client go in a callback group of their own, which the executor of the node does not take: the client serves it, and only it, while it waits for an answer (serve() brings what came meanwhile). So it calls from anywhere: before the node is spun, or from a callback of any executor, single threaded too.

It keeps the node only through weak pointers: the node, or the component that has it, may keep the client without a cycle; once the node is gone, calls get no answer.
