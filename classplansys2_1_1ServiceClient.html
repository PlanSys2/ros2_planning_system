Detailed Description

template<typename ServiceT>
class plansys2::ServiceClient< ServiceT >

A service client of a PlanSys2 client, which makes itself anew when an answer is lost.

A request that gets no answer in time is sent again with a new rclcpp client: new endpoints, discovered again. Some middlewares lose every answer to a client whose endpoints were matched badly while many processes started at once (Fast DDS, 2026-10-19), and waiting longer on the same client does not help. With more than one attempt, only for services whose requests may be repeated: queries, and changes that leave the same state when repeated. A call that ends without answer leaves a new client for the next one, whatever its attempts.

With an ActiveComponent, a call first waits until the component is active, and its server gone or a call without answer make the next one wait for it again. An answer saying that the component is not active (kNotActive) makes the call wait for it and send the request again.
